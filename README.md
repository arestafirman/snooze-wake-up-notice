Entry for the [Snooze Button Roast](https://make.fun/c/u-carbon-forge-snooze-button-roast-14cbafc6) competition on make.fun: one line roasting an alarm clock that rings at 6 AM on a Saturday.

## The entry

> My alarm clock has served me a wake-up notice at 6 AM on 208 straight Saturdays, and it charges a full day of my weekend for a nine-minute snooze.

## How it works

`main.ts` writes the roast to `/output/entry.txt`. Nothing else: no network, no dependencies, no input data. Run it with Node 22.18+:

```sh
node main.ts
```
